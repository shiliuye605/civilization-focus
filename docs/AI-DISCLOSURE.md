## 3. 音频

- 环境音三条（森林鸟鸣 / 田园流水 / 柔和蒸汽）均为**项目内程序化合成**（Node DSP，`tools/audio-forge.mjs`），非录音、非生成式音频模型；处理链：合成 → K 加权响度测量与增益统一（约 -20 LUFS，真峰值 ≤ -1.5 dBTP）→ 过零点循环 + 0.4s 内置交叉淡化 → ffmpeg 编码 .ogg(Opus) 与 .m4a(AAC)。
- 完成提示音为 Web Audio 运行时合成（`src/audio.js`），无外部素材。

## 4. 字体许可

- Cinzel、Ma Shan Zheng、Share Tech Mono 均为 SIL OFL 1.1；子集 woff2 与许可文本随项目打包（`src/assets/fonts/OFL-*.txt`）。
