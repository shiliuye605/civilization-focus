# 演示流程（2～3 分钟）与备用录屏

环境：生产构建（`npm ci && npm run build && npm run preview`，默认 http://localhost:4173）或已验收的公网地址；主目标浏览器 Chrome；建议窗口 1280×800。全程使用**演示模式**展示三时代，不消耗正式记录。

| 时间 | 操作 | 讲解点 |
| --- | --- | --- |
| 0:00–0:15 | 首页停留，轻拖地球旋转 | 一屏首页：本地时钟、设置齿轮、体素地球；无滚动条 |
| 0:15–0:35 | 点击地球 → 像素转场进入石器场景；点一个发光热点读图鉴；工具区开图鉴面板再 Esc | 石牌 HUD 计时已开始；转场不中断计时；图鉴插图为真实场景切片 |
| 0:35–0:50 | 回首页 → 设置 → 演示模式「进入演示模式」 | 每轮 15 秒 / 休息 5 秒、仅展示不计正式；正式轮运行中进入会先确认暂停 |
| 0:50–1:10 | 进场景等第一轮结算 → 解锁卡 → 进入盛唐 | 演示徽标全程可见；解锁卡只列真实新增内容；木牌 HUD 与 Ma Shan Zheng 字体 |
| 1:10–1:30 | 第二轮结算 → 解锁卡 → 进入蒸汽城镇 | 铁牌 HUD、Share Tech Mono 工业时钟；厂房/钟楼/铁轨全链路 |
| 1:30–1:50 | 工具区声音键：开启 → 静音 → 取消静音；回首页听太空默认，设置内选「田园流水」钉住再切回「自动」 | 默认关闭、首屏无音频请求；手势开启；首页默认太空、场景随时代（蒸汽火车）；手动钉住跨时代不跟随、选自动恢复；交叉淡化；刷新保留偏好但需点击恢复 |
| 1:50–2:10 | 窗口缩到手机宽度 → 工具区全景键 → 点两个热点 → 切回沉浸 | 全景扣除 HUD 安全区 contain 缩放，9 热点全部可达（≥44px）；切换不重建计时 |
| 2:10–2:30 | 回首页 → 设置 → 「退出演示，恢复正式进度」 | 正式轮次/分钟保持原值；演示零写入正式存档与声音偏好；保存失败有五类可见通知 |

## 备用录屏

- 文件：`docs/demo-recording.webm`（约 70 秒无声录屏，1280×800，生产构建实跑）。
- 覆盖：首页 → 设置进入演示 → 石器场景与图鉴面板 → 两轮演示结算与盛唐/蒸汽解锁 → 声音开关/静音 → 退出演示后正式进度为零。
- 未覆盖：全景/窄屏步骤（录屏为固定桌面视口），现场按上表 1:50–2:10 补演；如需窄屏录屏可另录。
- 复录：`node tools/demo-record.mjs`（临时脚本，不入库；依赖 playwright-core 与系统 Chrome，录屏需 `node node_modules/playwright-core/cli.js install ffmpeg`）。

## 注意

- 演示与正式共用计时/结算/解锁逻辑，仅时长与保存路径不同；退出或刷新自动回正式模式。
- 声音必须用户手势开启；开启后首页地球默认播「太空首页」、进入场景随时代切换；自动播放被拒时设置内有可见重试入口。
- WebGL 不可用时首页显示降级按钮，仍可进入计时；底图加载失败回退程序化画面，不黑屏。

## V0.6 人物看点（现场可指认）

- 石器：篝火旁坐姿打制——托石手稳定、持石手举落且落点在石芯上；搬运者篮筐/木料与手连接。
- 盛唐：田垄锄地四帧——锄刃入土带土屑、前倾自髋部、帽肩同步；宽檐笠下可见脸与右衽斜襟（不镜像）。
- 蒸汽：机旁扳手四帧——颚口始终压飞轮黄铜轮毂；卷袖亮前臂与马甲边在暗厂房中可读。
- 备用劳动录像：`tools/shots/v06/labor-{stone,tang,steam}.webm / .mp4`（1280×800 实跑，各含 ≥2 个完整劳动循环）；等高前后对照与盲测图见 `tools/shots/v06/d8-*.png`。
